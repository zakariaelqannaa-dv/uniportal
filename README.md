A modern, university-grade academic dashboard designed to seamlessly track student timetables, course loads, faculty office hours, and free-time analytics. Styled with a **Google Pixel Material You** aesthetic featuring soft pastels, fluid shapes, and an intuitive user interface.

---

## 🎯 Why We Built This Project

Managing university life can often feel scattered between course schedules, tracking weekly study hours, keeping up with professors' office hours, and balancing personal free time. 

This project was created to solve that by providing:
* **Centralized Academic Control:** A single source of truth for all university courses, rooms, and schedules.
* **Faculty Directory:** Quick access to teacher information, subjects taught, and office hours with live searching.
* **Productivity & Free-Time Analytics:** Visual data tracking how free time and hobbies are distributed alongside academic commitments.
* **Developer-Friendly Architecture:** Built with a solid Python backend logic model combined with a blazing-fast Vite web frontend and persistent local storage.

---

## 🛠️ Tech Stack & Tools

* **Frontend Framework & Bundler:** [Vite](https://vitejs.dev/) (Lightning-fast development server)
* **Styling & UI Design:** [Tailwind CSS](https://tailwindcss.com/) (Google Pixel / Material You theme)
* **Data Visualization:** [Chart.js](https://www.chartjs.org/) (Interactive free-time breakdown charts)
* **Backend Logic & Data Model:** Python (Dataclasses, JSON persistence, and object-oriented architecture)
* **Icons & Typography:** FontAwesome & Google Sans / Outfit typography

## 🚀 Getting Started & Quick Start

Follow these steps to run the dashboard locally on your machine:

### 1. Clone or Open the Repository
Open your terminal inside your project directory.

### 2. Install Dependencies
Make sure you have [Node.js](https://nodejs.org/) installed, then run:
``bash''
npm install

3. Run the Development Server
Launch Vite with hot-reloading enabled:

Bash
npm run dev
Open the local development URL provided in your terminal (usually http://localhost:5173) to view your dashboard!
